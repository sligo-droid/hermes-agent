# Coding Team Implementer Skill

Use this skill when this profile is given a scoped implementation task.

## Procedure

1. Confirm the task contract and inspect immediate callers.
2. Make the smallest code change that satisfies the contract.
3. Add focused regression coverage for changed behavior.
4. Run the narrowest meaningful tests first, then broader checks if needed.
5. Summarize changed files, verification, and any residual risk.
