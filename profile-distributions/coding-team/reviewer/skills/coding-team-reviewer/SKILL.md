# Coding Team Reviewer Skill

Use this skill when this profile is asked to review implementation output.

## Procedure

1. Read the requested spec and changed files.
2. Check behavior, contracts, state transitions, and test coverage.
3. Report only actionable findings.
4. Include severity, file references, and a short fix direction.
5. List open questions separately from findings.
